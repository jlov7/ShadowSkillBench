# Changelog

Notable software changes are recorded here. Package versions do not imply a
completed research protocol or a confirmatory finding.

## 0.1.0 - 2026-09-21

### Added

- Synthetic access-provisioning and financial-adjustment benchmark domains.
- Frozen compiler, executor, authority, audit, analysis, report, and offline
  reproduction contracts.
- Read-only ShadowSkill Workbench with static build and browser tests.
- Public governance, citation, security-reporting, SBOM, pack-manifest, and
  dependency-audit surfaces.

### Security and scientific integrity

- Source distributions now use an explicit allowlist and exclude local raw
  artifacts, protocol custody receipts, tests, and caches.
- Confirmatory analysis now requires the exact frozen statistics profile.
- Release findings now require sealed claim-to-estimand evidence with frozen
  direction, materiality, interval, and multiplicity bindings.
- Local custody now verifies the named Git commit, tag, and committed freeze
  bytes instead of accepting receipt-shaped content alone.

The confirmatory research path remains held pending its protocol, anchor,
execution, evidence, and human-review gates. This release publishes software
and method specifications only.
